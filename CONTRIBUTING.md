# Contributing

Thanks for helping improve **Board Game Night**!

## Ways to contribute
- Report bugs
- Suggest features
- Improve UI/UX
- Propose weighting ideas for voting

## Reporting Bugs
Please open an Issue and include:

1. **What happened?**
2. **What did you expect?**
3. **Steps to reproduce**
4. **Screenshots / screen recordings** (if helpful)
5. **Device + browser**
   - Example: “iPhone 14 / Safari” or “Windows / Chrome”
6. **Console errors** (if any)
   - Open DevTools → Console → copy/paste relevant messages

## Feature Requests
Please open an Issue and include:

1. **Problem / goal**
2. **Proposed solution**
3. **Alternatives considered** (optional)
4. **Why this matters** (for game night flow)

## Labels / Triage
Maintainers may add labels like:
- `bug`, `feature`, `enhancement`
- `ui`, `auth`, `firebase`, `group`, `voting`
- `needs-triage`, `blocked`

## Code Style
- Keep changes small and focused
- Prefer readable code over clever code
- Avoid big refactors in feature PRs unless discussed first

Thanks again!
